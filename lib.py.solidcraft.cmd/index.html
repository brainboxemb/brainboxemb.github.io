SolidCraft Commands (SCPC)

A lightweight Python interface for writing SolidCraft's own native commands without manually composing JSON.

SCPC uses the command names and parameters supported by SolidCraft itself. The library can export command JSON, run commands through the native CLI, or send them to an already open SolidCraft session.

Example

script = Script()
script.add("sketch.create", plane="XY", name="Base")
script.add("sketch.rectangle.two_point",
           p0=[0, 0], p1=[100, 60])
script.add("sketch.finish")
script.add("solid.extrude", distance="10 mm", body_name="Plate")

This page is a concise entry point; the implementation and examples are maintained in the source repository.
